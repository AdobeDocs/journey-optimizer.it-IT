# Avvertenza di sostituzione della parola chiave di rinuncia mobile

>[!IMPORTANT]
>
>Se definisci parole chiave di consenso, rinuncia, Guida o doppio consenso, queste sostituiscono le parole chiave predefinite di Adobe Journey Optimizer in entrata. Per mantenere funzionanti le impostazioni predefinite, aggiungerle esplicitamente insieme alle parole chiave personalizzate. [Ulteriori informazioni sulla gestione delle rinunce](/help/using/mobile/mobile-opt-out.md#sms-native-keywords)
>
